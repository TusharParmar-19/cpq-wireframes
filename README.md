# CPQ Wireframes - GitHub + Cloudflare Pages

This is a static HTML design-review prototype, not a functioning CPQ application.

## Repository structure

- `public/index.html` - review home page
- `public/CPQ_Wireframes_COMPLETE_59_SCREENS.html` - full interactive 59-screen wireframe
- `public/CPQ_Wireframes_Batch_*.html` - five review batches
- `public/previews/` - example PNG previews

## Cloudflare Pages Git settings

- Framework preset: None
- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `public`
- Root directory: leave as repository root

Do not upload sensitive data, credentials or real customer information. The Pages site is public unless Cloudflare Access is configured.
