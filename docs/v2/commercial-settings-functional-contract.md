# Phase 1 — Commercial Settings
A single global browser-local default set applies to all demo selling entities/branches; company-specific commercial controls are deferred. Validity 0–365 calendar days (0 = blank), optional default payment/delivery/warranty/exclusions, rounding none/nearest rupee and up to 20 reusable payment templates. Initial behavior unchanged: blank validity, placeholder terms, no rounding and three existing payment templates. Save creates a new version and preserves previous saved versions. Version check rejects stale edits. Existing user-entered terms, prices, tax, revisions, approvals and orders are never migrated or silently updated.
Only the fresh newBuilder path (including new quotes from opportunity or configuration handoff and new direct orders) copies defaults; direct orders omit validity. Edits, duplications and revisions preserve copied terms rather than resetting to master. Selecting a payment template explicitly replaces the draft's payment text only. Product rates and service classifications stay in masters. Discounts, subsidy and GST treatment remain explicit per transaction. No bank details, actual statutory tax, legal approval, permissions or advanced approval policy.
Phase 3 configuration rules: navigation removed, workflow disabled, original URL notice and isolated preview/engine preserved. Saved rule definitions/history retained without mutation; active saved status has no Phase 1 effect.
